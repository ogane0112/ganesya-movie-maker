# Marp スライドを台本の下書きにする

## 入力

- Marp のスライド（`.md`）。画像はスライドからの相対パスのまま置いてあること

## 手順

```sh
./bin/gmm.mjs marp <スライド.md> -o <台本.md>     # 既定は <スライド名>-video.md。上書きは --force
```

変換のきまり：

| スライド | 台本 |
| --- | --- |
| 1枚目（か `_class: lead`）の見出しだけのスライド | 表紙（`:::title`） |
| 見出し | シーンの見出し |
| 箇条書き（入れ子は親にまとめる） | `:::bullets` |
| コード・`$$` の数式・画像・引用・地の文 | `:::code`・`:::math`・`:::image`・`:::callout`・`:::text` |
| 表 | 「1列目：残りの列」の箇条書き（要確認つき） |
| 背景画像（`![bg]`） | 使わない（要確認） |
| 発表者ノート（Marp の指示でない `<!-- -->`） | ナレーション |
| ノートのないスライド | スライドの文を並べた仮のナレーション（`<!-- 下書き -->` の印） |

- stderr に、仮のナレーションのシーン数と `要確認` の一覧が出る。控えておく
- 画像のパスは台本からの相対パスに書き換わる。ネット上の画像は手元に保存してパスを直す

## 終わりの条件

- 台本ができた（この時点で `gmm check --tts silent` が書式エラーなく通る）
- 次は `gmm-explainer-script` の「スライドの下書きを直すとき」で、ナレーションと部品を直す
