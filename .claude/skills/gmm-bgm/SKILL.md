# BGM を選ぶ

## 入力

- 台本（動画の雰囲気：明るい入門・落ち着いた設計の話・失敗事例のふり返り・ゲーム実況 など）

## 手順

### カタログの曲

```sh
./bin/gmm.mjs bgm list            # 雰囲気・合う場面つきの一覧
./bin/gmm.mjs bgm list --tag 落ち着き
```

- 動画の雰囲気と、各曲の説明・タグ・「合う場面」を見比べて 1 曲選び、フロントマターに `bgm: maou:<曲ID>` と書く
- クレジット（「BGM: 魔王魂「曲名」」）は `credits.txt` に自動で出る
- 曲の音の大きさは自動でナレーションにそろうので、`bgmVolume` は基本そのまま（既定 0.3）。控えめにしたい回だけ 0.2 などに
- ゲーム実況では、ゲーム音があるので BGM なしでもよい（入れるなら `bgmVolume: 0.2` くらい）
- **エージェントは試聴できない。** 選んだ理由（どの説明・タグで選んだか）を利用者に伝え、聴いて確かめてもらう。
  良ければカタログ（`bgm/maou.json`）のその曲を `"heard": true` にする
- 曲は書き出し時に `bgm/cache/` へ自動で取ってくる。取れないとき（ネットワークの制限など）は、エラーに出る曲ページから
  MP3 を手で落として、示された場所に置いてもらう。`check` と `frames` は BGM なしでも進む
- カタログにない曲を使うときは、`bgm/maou.json` に曲ページ・説明・タグを足してから使う（音源ファイルはリポジトリに入れない。再配布禁止）

### モーション動画：曲の拍に合わせる

モーション動画も、**魔王魂などのカタログの曲を基本にする**（合成した曲より聴き慣れた音になる）。

```sh
./bin/gmm.mjs bgm list --tag モーション向け   # 疾走感のある曲（サイバー・ネオロック）
./bin/gmm.mjs bgm tempo maou:neorock54       # テンポと最初の小節の頭を測る
```

| 型 | 候補 |
| --- | --- |
| 紹介（ローンチ）・MV 風 | `maou:neorock54` / `maou:neorock33` / `maou:neorock25` |
| 技術紹介・3D | `maou:cyber01` / `maou:neorock36` |
| データ・歴史の物語 | `maou:piano37`（回想）/ `maou:piano35`（穏やか）/ `maou:acoustic51`（落ち着き） |

- 書き出し時に曲のテンポと最初の小節の頭を測り、場面の切れ目を曲の拍に、動画の頭を小節の頭にそろえる
- `gmm bgm tempo` の値を台本の `bpm:` に書く（曲を取れない `check` / `frames` でも長さが同じになる）。
  半分・倍の値でも拍はそろうので、場面の速さに合う方を選んでよい
- 「はっきりさ」が 0.3 未満の曲は拍が取りにくい。利用者に聴いてもらい、ずれていればカタログに `"bpm"` / `"offset"` を書くか、台本に `bgmOffset:` を書く
- 曲を取れない環境（ネットワークの制限）では、コードで合成する曲を使う：

| プリセット | 雰囲気 | 合う型 |
| --- | --- | --- |
| `synth:drive` | 明るく前に進む（4つ打ち・ベース・アルペジオ） | 製品紹介・MV 風 |
| `synth:tech` | 硬質でミニマル | 技術紹介・3D・データ |
| `synth:epic` | 壮大（太鼓・厚い和音） | 歴史・3D の見せ場 |
| `synth:chill` | 落ち着いた（ゆるいビート・柔らかい和音） | データの物語・まとめ |

- 調は `synth:drive@C` のように変えられる（既定 A）。テンポは台本の `bpm:`
- 音の大きさは自動でそろう。モーション動画の既定の `bgmVolume` は 0.8（ナレーション中は下がる）

## 終わりの条件

- フロントマターに `bgm:` がある（または BGM なしと決めた）
- 選んだ理由を、渡すときに伝えられるようにメモした
