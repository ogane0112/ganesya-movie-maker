## キャッシュ入門

:::title

なぜ速くなるのか

## キャッシュとは

{face:normal}{term:キャッシュ}キャッシュは、よく使うデータを近くに置いておくしくみなのだ。
一度取ってきたデータを覚えておけば、2回目からはすぐに返せるのだ。
{face:troubled}ただし、元のデータが変わると、覚えているデータは古くなるのだ。

:::bullets
- {1} よく使うデータを近くに置く
- {2} 2回目からは速く返せる
- {3} 古くなることがある {!3}
:::

## ヒット率

{face:normal}{term:ヒット率}効き目はヒット率で測るのだ。
アクセスのうち、キャッシュから返せた割合のことなのだ。

:::math {1}
\text{ヒット率} = \frac{\text{ヒット数}}{\text{アクセス数}}
:::

## 読み込みの流れ

読み込みの流れを、コードで見てみるのだ。
まずキャッシュを見て、あればそのまま返すのだ。
なければデータベースから取ってきて、キャッシュに覚えておくのだ。

:::code lang=ts {1} highlight="{2}:2-3 {3}:4-5"
async function get(key: string) {
  const hit = cache.get(key);
  if (hit) return hit;
  const value = await db.get(key);
  cache.set(key, value, { ttl: 60 });
  return value;
}
:::

## 消し方の比較

{face:think}古くなったデータの消し方は、主に2つあるのだ。
{term:TTL}TTLは、決めた秒数がたったら捨てる方法で、簡単だけどしばらく古いままなのだ。
書き込むときに消す方法は、すぐ新しくなるけど、消し忘れが起きやすいのだ。
{face:normal}迷ったら、まずTTLを短めにするのがおすすめなのだ。

:::bullets
- {2} TTL：簡単／しばらく古い
- {3} 書き込み時に消す：すぐ新しい／消し忘れる
:::

:::callout {4}
迷ったら、まず TTL を短めに
:::

## まとめ

{face:smile}まとめなのだ。

:::bullets

- {3} ヒット率で効き目を測る
