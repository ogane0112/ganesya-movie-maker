## そもそも何？

めたん: {face:think}{term:HTTP}そもそもHTTPって、ブラウザとサーバーの決まりごとよね？
ずんだもん: {face:normal}そうなのだ。
{term:ステータスコード}ステータスコードは、サーバーが返す結果を表す3桁の数字なのだ。

:::callout {3}
結果を表す3桁の数字
:::

## 百の位で分ける

ずんだもん: 百の位を見れば、だいたいの意味がわかるのだ。
2で始まれば成功、4ならお願いする側のミスなのだ。
5なら、サーバー側の失敗なのだ。
めたん: {face:normal}まずは百の位を見ればいいのね。

:::bullets
- {2} 2xx：成功
- {2} 4xx：お願いする側のミス
- {3} 5xx：サーバー側の失敗 {!3}
:::

## よく見る数字

めたん: {face:think}よく見る数字も教えてほしいわ。
ずんだもん: 404は、ページが見つからないという意味なのだ。
500は、サーバーの中で何かが壊れたという意味なのだ。

:::bullets
- {2} 404 Not Found：見つからない
- {3} 500 Internal Server Error：中で失敗
:::
