# 曲を作る・歌わせる

書式とコツは `docs/song.md`。見本は `examples/song/zunda-mochi.md`。`./bin/gmm.mjs new song <台本>` で見本から始められる。

## 入力

- 何の歌か（テーマ・雰囲気）、歌う人（既定はずんだもん）、長さ（既定 1〜2 分）、縦長か横長か
- 歌なしの BGM なら、使う動画の雰囲気と長さ

## 手順

### 1. 曲の骨組みを決める

- 伴奏の型（`music:`）とテンポ：明るい歌 pop 120〜140 / 元気 rock 150〜170 / しっとり ballad 70〜90 / ゲーム風 chiptune 140〜160 / ダンス edm 124〜130
- 構成：イントロ（4 小節）→ A メロ（8）→（B メロ 4〜8）→ サビ（8）→ アウトロ（4）。2 番まで作るならサビを繰り返す
- コード進行をセクションごとに決める（定番は `docs/song.md` の「作曲のコツ」）。サビは王道進行 `F G Em Am` などで盛り上げる

### 2. 歌詞を書く

- 先に歌詞を書き、1 フレーズ（2 小節）に 5〜9 音（モーラ）くらいに分ける。数え方：「きゃ」「しょ」は 1 音、「っ」「ん」「ー」も 1 音
- サビには題名か、繰り返す覚えやすい言葉を入れる。キャラの口ぐせ（「〜なのだ」）も使える
- `lyrics:` はひらがな、`text:` に漢字まじりの表示用を書く
- 勉強用の歌（用語を覚える替え歌）は、用語ごとに 1 セクション（4 小節・4 フレーズ）。歌詞は「意味 → 用語 → 仕組み → 使いどころ」の順に。
  **歌詞だけで済ませず、セクションに解説動画の部品（`:::diagram` `:::bullets` など）を書いて、スライドの図解に合わせて歌わせる**（`docs/song.md`「スライドの図解に合わせて歌う」）。
  `{n}` は n 番目のフレーズ。図の箱や箇条書きは、その言葉を歌うフレーズで出す。見出しは「用語：一言の意味」
- 内容が正しいか（試験の範囲・定義）は確かめ、自信がない所は利用者に伝える

### 替え歌のとき

- 旋律を借りてよいのは著作権の切れた曲だけ（クラシック・童謡・民謡など）。最近の曲は断り、オリジナルを提案する
- 旋律は覚えている音で書くので、原曲と違う所がありうると利用者に伝える
- 原曲が 2/4 拍子なら 2 小節を 1 小節にまとめ、`grid=16` で書く（見本 `examples/song/ap-cancan.md`）
- 速い曲は言葉が詰まって聞き取りにくい。16 分音符に 1 音なら 120 BPM 前後まで落とす

### 3. メロディを書く

- 歌詞の音の数と、`melody:` の音の数（`-` と `.` を除く）を必ずそろえる。1 小節 = 8 升を `|` で区切る
- 強い拍はコードの音、高さは `C4`〜`C5` 中心（サビで `D5`〜`E5` まで）。跳躍は 5 度まで
- フレーズの終わりは伸ばすか休んで、息つぎの間を作る
- 迷ったら、まず全部 4 分音符（`C4 - D4 - E4 - F4 -`）で書き、言葉に合わせて 8 分に崩す

### 4. 確かめる

```sh
./bin/gmm.mjs check <台本>      # 書式エラー（終了コード 2）は行番号のとおり直す。歌える高さ（song-range）の警告も直す
./bin/gmm.mjs song <台本>       # build/<台本名>/song.wav を作る
```

- 音は聴けないので、`ffmpeg -i song.wav -lavfi showspectrumpic=s=1600x500 spec.png` の画像で、歌（横に並ぶ倍音の線）が入っているかを見る
- 動画にするなら `gmm-review` → `gmm-render`。歌詞の字幕がフレーズごとに出て、カラオケで色付くか、図解が歌に合わせて出るかを `gmm frames --steps` で見る
- VOICEVOX が動いていないと歌は入らない（楽器がメロディを弾く）。書き出しの前に `gmm-setup` で起動を確かめる

## 渡すときに伝えること

- 曲（`song.wav`）と動画、`credits.txt`（「VOICEVOX:ずんだもん」など）
- テンポ・伴奏の型・コード進行・構成
- 聴いて確かめていないこと（音程・言葉の聞き取りやすさ・音量のバランス）

## 終わりの条件

- `gmm check` が書式エラーなし・`song-range` の警告なし
- `song.wav` ができ、スペクトルの画像で歌と伴奏が入っているのを見た
- 次は（動画にするなら）`gmm-review` → `gmm-render`
