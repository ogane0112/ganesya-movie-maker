# ゲーム実況・RTA 動画を作る（biim システム）

録画（利用者が用意する）と、録画の時刻に結び付けた実況台本から、biim システムの動画を作る。
台本の書き方は [references/rta-script-format.md](references/rta-script-format.md)。

## 進め方

### 1. 前提をそろえる

- VOICEVOX が動いているか: `curl -s localhost:50021/version`（止まっていれば起動。書き出しには必須）
- 録画ファイルの場所を利用者に聞く。台本と同じフォルダか、その下に置いてもらう
- 立ち絵: ずんだもんは `characters/zundamon/`（なければ `gmm character import`）。
  四国めたんは素材がなければ `builtin-metan`（組み込みキャラの色違い）で代用し、そのことを伝える
- わからなければ聞くこと：ゲーム名・レギュレーション（Any% など）・計測の開始と終了の基準（ゲームごとに違う）

### 2. 録画を下見する

```sh
./bin/gmm.mjs footage <録画> --every 5          # 5秒ごとのコマ一覧（1枚12コマ）と、暗転区間の !cut 候補
./bin/gmm.mjs footage <録画> --every 1 --from 1:20 --to 1:40   # 気になる所を細かく
```

- 出力された `footage/sheet-NN.png` を**全部**画像として見る。各コマの左下が録画の時刻
- 見ながらメモを作る：区間の切れ目（ステージ・エリアが変わる時刻）、見どころ（ボス・難所・ミス・ショートカット）、
  何も起きない長い移動（倍速の候補）、計測の開始・終了らしい時刻
- 暗転の候補は、本当にロードかをコマで確かめてから `!cut` にする（演出の暗転は切らない）

### 3. 台本の骨組みを作る

- フロントマター：`layout: biim`・`video:`・`runStart:`・`runEnd:`・`title:`（「ゲーム名 カテゴリ RTA 最終タイム」）・`category:`・`speakers:`・`characters:`
- `!cut`（ロード）と `!fast`（長い移動。x4 など）を書く
- 区間を `## 名前 @時刻` で並べる。区間の名前は画面のステージ名に合わせる。区間は多すぎない（5〜15 程度）

### 4. 実況を下書きする

役割：**ずんだもん = 走者（作戦やテクニックを説明する）、四国めたん = 聞き役（疑問・感想・ツッコミ）**。

- 各発言の前に `@時刻` を書き、**その時刻にコマで実際に見えていること**について話す。見えていないことは書かない
- ゲームの知識（技の名前・乱数・ルート選択の理由など）でコマから確かめられないことは、断定せず
  `<!-- 要確認: ○○ -->` を書いて利用者に聞く。でっち上げない
- 10〜20 秒に 1〜2 発言が目安。ゲームの見せ場（ボス・難所）では黙る時間も作る
- 1 発言は短く（字幕 2 行まで）。長い説明は 2 人で分ける
- 冒頭は「はい、よーいスタート」から始めて、レギュレーションとタイマーの基準を一言で説明するのが定番
- 終わりは最終タイムと感想、「ご視聴ありがとうございました」
- 専門用語（「乱数」「グリッチ」「フレーム」など）は glossary に書き、初めて出る所で説明する（`{term:用語}`）
- 表情：成功で `smile`、ミスで `troubled`、驚きで `surprised`、作戦説明で `think`。区切りで `normal` に戻す
- 内輪ネタ・特定の人を揶揄するネタ・差別的なネタは使わない

### 5. 検査とキーフレームで直す

```sh
./bin/gmm.mjs check <台本>
./bin/gmm.mjs frames <台本>                         # 区間ごとの最終フレーム
./bin/gmm.mjs frames <台本> --steps --scene s03     # 発言ごとの画面（字幕・話者・ゲーム画面）
```

- `lag`（発言が指定した時刻より遅れる）は、前の発言を削るか短くする。映像と話がずれるので必ず直す
- `past-end`（録画の終わりを越える）は、終わりの発言を減らす
- キーフレームで、話している内容とゲーム画面が合っているかを見る

### 6. 書き出して渡す

```sh
./bin/gmm.mjs render <台本>     # 変わった区間だけ書き出し直す
```

- 渡すときに伝えること：`<!-- 要確認 -->` の箇所、AI が見たのは数秒おきのコマだけであること（ゲーム音・細かい操作は見ていない）、
  `credits.txt` のクレジット（VOICEVOX・立ち絵・BGM）
