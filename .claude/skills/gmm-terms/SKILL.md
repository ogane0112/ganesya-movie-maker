# 専門用語を説明させる

動画では、**専門用語は必ず一度、最初に使う所で説明する**。

## 入力

- 書きかけ／書き終えた台本

## 手順

1. 視聴者が知らないかもしれない語を、台本のフロントマターの `glossary:` に「用語: 一言の説明」で書く
2. 候補の一覧で漏れを探す：

   ```sh
   ./bin/gmm.mjs terms <台本>
   ```

   カタカナ語・英字の語が、回数・初出のシーン・glossary の有無・説明の有無つきで出る。
   漢字の語（例: 冪等性）は候補に出ないので自分で拾う
3. 説明する文の文頭に `{term:用語}` を付ける。説明は「〇〇は、△△のことなのだ。」のように一文で言い切る
4. 中心になる概念は `:::term {n}` の用語カードで画面にも出す（出た文で説明したことになる）
5. 説明は、その用語を使う**最初のシーン**で行う。表紙・エンディング（`:::title` のシーン）で題名として使うのは構わない
6. `./bin/gmm.mjs check <台本> --tts silent` で確かめる：
   - 説明している文がない用語 → エラー
   - 説明より前のシーンで使っている用語 → 警告（同じシーン内なら直後の説明でよい）
   - glossary にあるのに使っていない用語 → 警告

ゲーム実況では「乱数」「グリッチ」「フレーム」「Any%」などが専門用語になる。

## 終わりの条件

- `gmm check` に用語のエラー・警告がない
- 説明の文を読んで、説明になっている（言い換えただけになっていない）
