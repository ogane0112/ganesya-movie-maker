---

## キャッシュとは

- よく使うデータを近くに置く
- 2回目からは速く返せる
- 古くなることがある

<!--
キャッシュは、よく使うデータを近くに置いておくしくみです。
一度取ってきたデータを覚えておけば、2回目からはすぐに返せます。
ただし、元のデータが変わると、覚えているデータは古くなります。
-->

---

## ヒット率

$$
\text{ヒット率} = \frac{\text{ヒット数}}{\text{アクセス数}}
$$

<!--
キャッシュの効き目は、ヒット率で測ります。
アクセスのうち、キャッシュから返せた割合です。
-->

---

## 読み込みの流れ

```ts
async function get(key: string) {
  const hit = cache.get(key);
  if (hit) return hit;
  const value = await db.get(key);
  cache.set(key, value, { ttl: 60 });
  return value;
}
```

---

## 消し方の比較

| 方法 | よいところ | 困るところ |
| --- | --- | --- |
| TTL | 簡単 | しばらく古い |
| 書き込み時に消す | すぐ新しい | 消し忘れる |

> 迷ったら、まず TTL を短めに

---

## まとめ

- よく使うデータを近くに置く
- ヒット率で効き目を測る
- 古くなる問題とつきあう
