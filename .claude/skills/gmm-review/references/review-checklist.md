# キーフレームの確認項目

`gmm check` に合格したあと、`build/<台本名>/frames/overview.png` を見て確かめる。
気になるシーンは `gmm frames <台本> --steps --scene sXX` で文ごとに見る（字幕は文ごとの画像にだけ出る）。

## 内容

- [ ] 専門用語は、最初に出てくる所で説明されている（`check` が通っていれば仕組み上は満たす。説明が説明になっているかを読む）
- [ ] 画面に出る順番が、話す順番と合っている（先に画面に答えが出ていない）
- [ ] 画面の言葉とナレーションの言葉がそろっている（同じものを別の名前で呼んでいない）
- [ ] コードのハイライトが、その文で話している行に当たっている
- [ ] まとめの項目が、本編で話した内容と一致している

## 見た目

- [ ] 文字が小さすぎない・詰め込みすぎていない（遠目に読める）
- [ ] 画面の上半分に寄りすぎていない、空白が大きく偏っていない
- [ ] 図解の矢印の向きとラベルが正しい
- [ ] 字幕が読みやすい位置・長さになっている（2 行まで、改行位置が不自然でない）

## 立ち絵

- [ ] 表情が話の内容に合っている（問題の場面で笑顔のまま、などがない）
- [ ] 驚き・困りが長く続いていない
- [ ] 部品が立ち絵に隠れていない

## 音声（MP4 を書き出したあと、必要なら）

- [ ] 読み間違いがない（固有名詞・英字・数字）。気になる語は `readings:` で直す

## ゲーム実況（layout: biim）

- [ ] 話している内容と、そのときのゲーム画面が合っている（`--steps` で発言ごとに見る）
- [ ] 区間の名前とタイマーの切り替わりが、画面のステージの変わり目と合っている
- [ ] 小ネタ（右の欄）が欄に収まり、その場面に合っている
- [ ] 立ち絵がゲームの大事な所（自キャラ・HUD）を隠していない

## モーション動画（layout: motion）

- [ ] 大きな文字が一目で読める（長すぎない・背景に埋もれていない）
- [ ] 場面の見出しを上から読むだけで話が通じる。前の場面の問いに次の場面が答えていて、唐突に手順や機能に入っていない
- [ ] 文字どうしが重なっていない（`text-overlap`）
- [ ] 場面の内容と曲の雰囲気が合っている（合成した曲は試聴できないので、利用者に聴いてもらう）
- [ ] 数字・年が正しく、出典を確かめた
- [ ] 場面のコード（:::custom）の見た目が、`--steps` のどのコマでも崩れていない
